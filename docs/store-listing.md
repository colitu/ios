# App Store listing draft

**Name:** Colitu Secure VPN

**Subtitle:** Private access, clear pricing

**Description:** Colitu provides account-based VPN access with a free plan (10 GB every month, one device) and transparent per-device plans. Server eligibility and configuration come from the Colitu API. The Network Extension establishes the VPN tunnel; hosted Platega checkout handles supported payments outside the app where store policy permits.

Required before submission: iPhone/iPad screenshots, App Privacy answers verified against the archive privacy report, export-compliance response, support/privacy URLs, review notes and test account, physical-device Network Extension smoke evidence and a signed archive produced by Codemagic.
